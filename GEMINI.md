## 2. Обязательный регламент Git-синхронизации

### Когда делать коммит и push
- Коммит и push выполняются **после завершения каждого полноценного этапа / задачи**.
- **Не делать** коммиты после каждой мелкой промежуточной правки. Публикуются только завершённые, целостные и проверенные результаты работы.

### Чеклист перед каждым коммитом
1. **Проверка статуса и диффа:**
   - Выполнить `git status` и `git diff`.
   - Убедиться, что в staged/untracked нет лишних файлов.
2. **Безопасность и гигиена:**
   - **Категорически запрещено** добавлять токены, пароли, API-ключи, `.env*`, дампы, временные файлы и ненужные сборочные кэши.
   - Проверять актуальность `.gitignore`.
3. **Верификация работоспособности:**
   - Запустить релевантные проверки проекта (`npx playwright test`, синтаксис, типы, тесты ассетов).
   - Ни при каких обстоятельствах **не публиковать заведомо сломанные изменения**.

### Правила коммита и отправки (Push)
1. **Сообщения коммитов:**
   - Использовать понятные, информативные сообщения на русском или английском (предпочтительно Conventional Commits: `feat: ...`, `fix: ...`, `docs: ...`, `refactor: ...`), точно отражающие суть изменений.
2. **Безопасный push:**
   - **Никогда не выполнять force push** (`git push --force`, `-f`).
   - Не перезаписывать чужие коммиты.
   - Выполнять стандартный push: `git push origin main`.
3. **Контроль доставки:**
   - После выполнения `git push` обязательно проверить, что коммит зафиксирован в удалённой ветке (`git log -1 --stat`, либо `gh repo view fen3211/nova-gear`).
   - Если push завершился ошибкой — немедленно сообщить о проблеме пользователю с точной причиной и диагностикой. **Запрещено утверждать, что синхронизация выполнена, если push завершился сбоем**.
4. **Конфиденциальность:**
   - Гарантировать приватный статус репозитория при любых операциях.

## 3. Стек проекта и архитектурные стандарты
- **Frontend:** Чистый семантический HTML5, современный адаптивный CSS3 (fluid `clamp()`, grid, flexbox, zero runtime frameworks), Vanilla JavaScript (ES2022+).
- **3D & Visuals:** Blender 5.2.2 LTS (Cycles GPU / OptiX, AgX Color Management), фотореалистичные PBR-материалы, бесшовные WebM (VP9 + alpha) / WebP / PNG изолированные слои с мягкими контактными тенями.
- **Тестирование:** Playwright Test Suite (`tests/suite.spec.ts`) с попиксельной проверкой альфа-каналов Canvas и визуальной стабильности карточек.
